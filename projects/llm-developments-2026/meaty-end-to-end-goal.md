# Meaty End-to-End Goal

Turn `LLMDevelopments.pdf` from a reading list into a production experiment program.

The end-to-end outcome is not:

- a paper summary
- a bibliography
- a general trend memo

The end-to-end outcome is:

- a measurable retrieval and context-systems layer
- a measurable reasoning and verifier layer
- a measurable agent-harness and workflow layer
- a measurable long-horizon CLI evaluation layer
- a measurable long-context and inference-systems prototype lane
- a production adoption path into `projects/coding-agent-v1/`

The track is complete when the repo can answer these questions with evidence:

1. When should a system use lexical, vector, or hybrid retrieval?
2. When should retrieved or tool-produced context stay inline versus move behind pointers?
3. Do repo instruction files improve quality enough to justify their cost?
4. How much does verifier-backed multi-attempt reasoning improve reliability?
5. What should a long-running agent handoff artifact contain?
6. Which long-context systems ideas from this paper list survive reduced-prototype testing?
7. Which ideas should be promoted into the default coding-agent harness, and which should stay experimental?
